--------------------------------------------------------------------------------
Method: POST
Path: /api/playthroughs/{playthroughUid}/sessions/stop

Path Parameters:
- playthroughUid (string): Unique identifier of the playthrough

{
  "timeBookingUid": "string",
  "startedAt": "2024-01-01T12:00:00Z" | null,  // ISO-8601 Instant format
  "stoppedAt": "2024-01-01T13:00:00Z" | null,  // ISO-8601 Instant format
  "durationSeconds": 3600  // long integer

5. QUERY ENDPOINTS – GAME OVERVIEW
================================================================================
Base Path: /api/query/game-overview

--------------------------------------------------------------------------------
5.1 Game Overview Query
--------------------------------------------------------------------------------
Method: POST
Path: /api/query/game-overview
Content-Type: application/json

Request Body:
{
  "searchText": "string" | null,           // optional; LIKE %text% on game name
  "platformUids": [ "string" ] | null,     // optional; filter by platform UIDs
  "consoleUids": [ "string" ] | null,      // optional; filter by console UIDs
  "inBacklog": true | false | null,        // optional; filter by backlog state
  "hasActivePlaythrough": true | false | null,  // optional
  "completionStateUids": [ "string" ] | null,   // optional; filter by completion
  "sortMode": "NAME_ASC" | "NAME_DESC" | "PLAYTIME_DESC" | "LAST_PLAYED_DESC"
}

SortMode enum:
- NAME_ASC
- NAME_DESC
- PLAYTIME_DESC
- LAST_PLAYED_DESC

Response: 200 OK
Array of GameOverviewRowDto:
[
  {
    "gameUid": "string",
    "gameInstanceUid": "string" | null,     // null if no instance exists
    "hasInstance": true | false,
    "gameName": "string",
    "releaseYear": 2024 | null,
    "platformUid": "string",
    "platformName": "string",
    "variantUid": "string",
    "variantName": "string",
    "inBacklog": true | false,
    "hasActivePlaythrough": true | false,
    "completionStateUid": "string" | null,
    "totalPlaytimeSeconds": 0,
    "thumbnailImageUid": "string" | null
  }
]

NOTES
================================================================================
- All endpoints return JSON responses
- Date formats:
  * LocalDate: YYYY-MM-DD (e.g., "2024-01-15")
  * Instant: ISO-8601 format with timezone (e.g., "2024-01-15T12:00:00Z")
- All UIDs are string values
- Error responses are not explicitly defined in the current implementation
- The API uses Spring Boot's default error handling
